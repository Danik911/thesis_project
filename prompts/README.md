# Historical Prompts Reference

This directory contains **reference prompts from thesis development** — they are not actively used by the current system.

## Contents

- `ai-code-judge-prompt.md` — Original AI code review prompt
- `ai-code-judge-prompt-v2.md` — Improved version with refinements
- `pharmaceutical-code-review-prompt.md` — Specialized pharmaceutical domain code review prompt

## Purpose

These files serve as **examples of pharmaceutical-domain prompt engineering** and document the evolution of code review strategies during thesis work.

## Current System

Active prompts are located in:
- `main/src/lims/prompts/` — AI4LIMS feature-specific prompts
- Agent code (.claude/agents/) — Embedded prompts for subagent workflows

For prompt modifications, update those active locations instead of these reference files.
