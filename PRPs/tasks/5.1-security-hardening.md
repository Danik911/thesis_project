# Task P5.1 – Post-Cutover Security Hardening

## What to Do
- Enable AWS WAF with managed rules for the frontend CloudFront distribution.
- Rotate all Secrets Manager credentials and enforce rotation policies.
- Conduct container image signing (e.g., cosign) and verify in CI before deployments.

## Dependencies
- Requires production infrastructure live (Phase 4 completion).

## Best Practices
- Document WAF rules and exceptions, mapping to compliance controls.
- Use AWS Config to ensure secrets rotation compliance and alert on violations.
- Sign images after scanning to maintain integrity chain.

## Links
- [AWS WAF Security Automations](https://docs.aws.amazon.com/waf/latest/developerguide/security-automations.html)

## Testing Strategy
- Run penetration test or automated DAST scan of API endpoints.
- Verify WAF blocks known malicious payloads while allowing legitimate traffic.
- Ensure ECS deploy pipeline fails if image signature missing or invalid.

## Common Issues to Avoid
- Deploying WAF in count mode only without enforcing blocks.
- Forgetting to update services with rotated secrets, causing runtime failures.
- Skipping signing verification step in CI/CD.
