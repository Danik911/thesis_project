# Task P6.2 – HMAC-Based Job Ownership Verification

## Priority: CRITICAL
## OWASP Reference: A01:2021 - Broken Access Control
## Compliance: 21 CFR Part 11 §11.10(d), GAMP-5

---

## Problem Statement

The current authorization check in `app.py` relies on simple string comparison between `job.user_id` and `current_user.sub` (from Clerk JWT). This is vulnerable to:

1. **Horizontal Privilege Escalation**: If JWT claims can be manipulated
2. **Race Conditions**: Between job creation and access check
3. **Lack of Cryptographic Verification**: No proof of ownership beyond JWT claim

### Current Vulnerable Pattern (6 locations in app.py)

```python
# Lines 596, 650, 737, 857, 1024, 1242
if job.user_id != user.sub:
    raise HTTPException(status_code=403, detail="Not authorized")
```

### Attack Scenario

1. Attacker obtains valid JWT for their account
2. Attacker discovers job IDs belonging to other users (sequential, predictable, or enumerated)
3. If JWT validation is bypassed or claims are spoofed, attacker accesses other users' URS documents and test results

## What to Do

### 1. Implement HMAC-Based Ownership Token

Create cryptographic proof of job ownership at creation time:

```python
import hmac
import hashlib
from datetime import UTC, datetime
import os

class JobOwnershipService:
    """
    Cryptographic job ownership verification for 21 CFR Part 11 compliance.
    """

    def __init__(self):
        self.secret_key = os.getenv("JOB_OWNERSHIP_SECRET_KEY")
        if not self.secret_key:
            raise RuntimeError("JOB_OWNERSHIP_SECRET_KEY not configured")

    def generate_ownership_token(
        self,
        job_id: str,
        user_id: str,
        created_at: datetime
    ) -> str:
        """
        Generate HMAC-SHA256 ownership token.

        Token = HMAC-SHA256(secret_key, job_id + user_id + timestamp)
        """
        message = f"{job_id}:{user_id}:{created_at.isoformat()}"
        token = hmac.new(
            self.secret_key.encode(),
            message.encode(),
            hashlib.sha256
        ).hexdigest()
        return token

    def verify_ownership(
        self,
        job_id: str,
        user_id: str,
        created_at: datetime,
        ownership_token: str
    ) -> bool:
        """
        Verify job ownership cryptographically.

        Returns True only if the token matches the expected value.
        NO FALLBACKS - invalid token means access denied.
        """
        expected_token = self.generate_ownership_token(job_id, user_id, created_at)
        return hmac.compare_digest(expected_token, ownership_token)
```

### 3. Create Authorization Dependency

Replace inline checks with a reusable dependency:

```python
# main/api/dependencies.py

from fastapi import Depends, HTTPException, status
from typing import Annotated

class AuthorizedJobAccess:
    """
    FastAPI dependency for cryptographically verified job access.

    Implements 21 CFR Part 11 §11.10(d): Limiting system access to authorized individuals.
    """

    def __init__(self):
        self.ownership_service = JobOwnershipService()

    async def __call__(
        self,
        job_id: str,
        user: ClerkClaims = Depends(get_current_user),
        job_repository: JobRepository = Depends(get_job_repository)
    ) -> JobRecord:
        """
        Verify user is authorized to access the job.

        Performs:
        1. Job existence check
        2. User ID comparison
        3. Cryptographic ownership verification
        4. Audit logging
        """
        job = job_repository.get(job_id)

        if not job:
            # Log access attempt for non-existent job
            await self._log_access_attempt(user.sub, job_id, "job_not_found")
            raise HTTPException(
                status_code=status.HTTP_404_NOT_FOUND,
                detail="Job not found"
            )

        # Cryptographic ownership verification
        if not job.verify_owner(user.sub, self.ownership_service):
            await self._log_access_attempt(
                user.sub, job_id, "ownership_verification_failed",
                actual_owner=job.user_id
            )
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail="Not authorized to access this job"
            )

        # Log successful access
        await self._log_access_attempt(user.sub, job_id, "access_granted")

        return job

    async def _log_access_attempt(
        self,
        user_id: str,
        job_id: str,
        result: str,
        **kwargs
    ) -> None:
        """Log access attempt for audit trail (21 CFR Part 11)."""
        # Integration with audit logger
        pass

# Type alias for dependency injection
AuthorizedJobDep = Annotated[JobRecord, Depends(AuthorizedJobAccess())]
```

## Best Practices

1. **Use constant-time comparison**: Always use `hmac.compare_digest()` to prevent timing attacks
2. **Secret key rotation**: Implement key rotation strategy (future enhancement)
3. **Audit all access**: Log both successful and failed access attempts
4. **No fallbacks**: If verification fails, deny access explicitly
5. **Defense in depth**: Keep JWT validation + add ownership verification

```python
def test_ownership_token_generation():
    """Test HMAC token generation."""
    service = JobOwnershipService()
    token = service.generate_ownership_token(
        job_id="job-123",
        user_id="user-456",
        created_at=datetime(2025, 1, 1, tzinfo=UTC)
    )
    assert len(token) == 64  # SHA256 hex

def test_ownership_verification_success():
    """Test valid ownership verification."""
    service = JobOwnershipService()
    job_id, user_id = "job-123", "user-456"
    created_at = datetime.now(UTC)

    token = service.generate_ownership_token(job_id, user_id, created_at)
    assert service.verify_ownership(job_id, user_id, created_at, token)

def test_ownership_verification_wrong_user():
    """Test that wrong user fails verification."""
    service = JobOwnershipService()
    token = service.generate_ownership_token("job-123", "user-456", datetime.now(UTC))

    # Different user trying to access
    assert not service.verify_ownership(
        "job-123", "attacker-789", datetime.now(UTC), token
    )

def test_ownership_verification_tampered_token():
    """Test that tampered tokens are rejected."""
    service = JobOwnershipService()
    token = service.generate_ownership_token("job-123", "user-456", datetime.now(UTC))

    tampered_token = token[:-1] + ("0" if token[-1] != "0" else "1")
    assert not service.verify_ownership(
        "job-123", "user-456", datetime.now(UTC), tampered_token
    )
```

## Common Issues to Avoid

1. **Using `==` for token comparison**: Always use `hmac.compare_digest()`
2. **Storing secret in code**: Use environment variable or Secrets Manager
3. **Missing migration**: Existing jobs need tokens generated
4. **Logging tokens**: Never log ownership tokens, even in debug mode
5. **Weak secret key**: Use cryptographically random key (32+ bytes)

## Migration Strategy

For existing jobs without ownership tokens:

```python
async def backfill_ownership_tokens(job_repository, ownership_service):
    """One-time migration to add ownership tokens to existing jobs."""
    for job in job_repository.all():
        if not job.ownership_token:
            job.ownership_token = ownership_service.generate_ownership_token(
                job.job_id, job.user_id, job.created_at
            )
            job_repository.update(job)
```
