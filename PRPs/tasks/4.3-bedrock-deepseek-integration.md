# Task P4.3 – Bedrock DeepSeek-V3.1 Integration

## What to Do
- Replace OpenRouter client with native Bedrock SDK integration using DeepSeek-V3.1 model.
- Implement throttling and retry logic aligned with Bedrock quotas.
- Update prompts to capture trace metadata for LangFuse while adhering to PHI masking rules.

## Dependencies
- Requires backend asynchronous submission (Task P1.3) and LangFuse observability (Task 6).

## Best Practices
- Parameterize model ID and inference configuration in environment variables for future upgrades.
- Use Bedrock Guardrails or prompt filters to enforce compliance with ALCOA+.
- Cache model responses where permissible to reduce inference cost and latency.

## Code Example
```python
import boto3
import json

bedrock = boto3.client('bedrock-runtime', region_name='eu-central-1')

def invoke_deepseek(prompt: str) -> str:
    response = bedrock.invoke_model(
        modelId="deepseek-v3.1",
        contentType="application/json",
        accept="application/json",
        body=json.dumps({
            "input": prompt,
            "maxTokens": 2048,
            "temperature": 0.2
        }),
    )
    return json.loads(response['body'].read())['output']
```
