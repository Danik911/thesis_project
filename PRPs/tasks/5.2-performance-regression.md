# Task P5.2 – Performance Regression & Capacity Planning

## What to Do
- Run comprehensive performance regression suite (ingestion + retrieval) against production-like dataset.
- Analyze LangFuse metrics to confirm latency budgets and throughput targets.
- Update capacity planning document with scaling thresholds and cost projections.

## Dependencies
- Requires Bedrock integration (Task P4.3) and observability dashboards (Task P2.3).

## Best Practices
- Use repeatable load patterns (e.g., k6 scripts) with production request mix.
- Compare results to baseline metrics captured pre-migration.
- Document findings and remediation actions in compliance repository.

## Links
- [k6 CloudWatch integration](https://k6.io/docs/results-visualization/cloudwatch/)

## Testing Strategy
- Execute k6 tests via CI with environment-specific parameters.
- Validate SQS queue depth and ECS autoscaling respond as expected under load.
- Confirm LangFuse traces do not show increased error rates post-optimization.

## Common Issues to Avoid
- Running tests against production without throttling, risking service disruption.
- Ignoring cost implications of higher desired counts during peak load.
- Forgetting to update documentation with new scaling thresholds.
