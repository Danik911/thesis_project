# Task P4.2 – S3 + ChromaDB Lambda (Context Provider)

## What to Do
- Deploy ChromaDB-based RAG context provider as AWS Lambda function in eu-west-2
- Upload compressed ChromaDB tarball to S3 bucket for Lambda access
- Configure EventBridge warm-up schedule to prevent cold starts
- Integrate Lambda with ECS worker for regulatory document retrieval

## Why This Approach (vs Aurora pgvector)

**Original plan:** Aurora Serverless v2 + pgvector (~$150/month)
**Chosen approach:** S3 + ChromaDB Lambda (~$2/month)

| Factor | Aurora pgvector | S3 + ChromaDB Lambda |
|--------|-----------------|---------------------|
| Monthly Cost | ~$150 | ~$2 |
| Complexity | High (managed DB) | Low (serverless) |
| Cold Start | 15-30s (Aurora pause) | 5-10s (Lambda) |
| Dataset Size | Overkill for 26 docs | Perfect fit |
| Update Frequency | Real-time | Quarterly rebuild |

**Rationale:** For 26 static regulatory documents with quarterly FDA guidance updates, a full managed database is overkill. Lambda-based ChromaDB provides equivalent RAG quality at 98.7% cost reduction.

## Dependencies
- S3 bucket for ChromaDB storage (pharma-vectors-eu)
- Lambda layer with ChromaDB dependencies
- ECS worker service (Task 4.1) for invoking Lambda

## Code Example

### Lambda Handler (aws/lambda/context_provider/lambda_function.py)
```python
import json
import os
import tarfile
import boto3
import chromadb
from chromadb.config import Settings

S3_BUCKET = os.environ.get('S3_BUCKET', 'pharma-vectors-eu')
S3_KEY = os.environ.get('S3_KEY', 'chroma_db.tar.gz')
CHROMA_PATH = '/tmp/chroma_db'

# Global cache for warm invocations
_collection = None

def get_chroma_collection():
    """Initialize ChromaDB (cached across warm invocations)."""
    global _collection
    if _collection is None:
        # Download and extract on cold start
        s3 = boto3.client('s3')
        s3.download_file(S3_BUCKET, S3_KEY, '/tmp/chroma_db.tar.gz')
        with tarfile.open('/tmp/chroma_db.tar.gz', 'r:gz') as tar:
            tar.extractall('/tmp/')

        client = chromadb.PersistentClient(path=CHROMA_PATH)
        _collection = client.get_collection('regulatory_docs')
    return _collection

def lambda_handler(event, context):
    """Query ChromaDB for regulatory context."""
    # Handle warm-up pings
    if event.get('source') == 'aws.events':
        get_chroma_collection()  # Pre-load
        return {'statusCode': 200, 'body': '{"status": "warmed"}'}

    # Query with embedding
    embedding = event['embedding']
    n_results = event.get('n_results', 5)

    collection = get_chroma_collection()
    results = collection.query(
        query_embeddings=[embedding],
        n_results=n_results,
        include=['documents', 'metadatas', 'distances']
    )

    return {
        'statusCode': 200,
        'body': json.dumps({
            'documents': results['documents'][0],
            'metadatas': results['metadatas'][0],
            'distances': results['distances'][0]
        })
    }
```

### ECS Worker Integration
```python
import boto3
import json

lambda_client = boto3.client('lambda', region_name='eu-west-2')

def query_regulatory_context(query_embedding: list[float], top_k: int = 5) -> dict:
    """Invoke Lambda for RAG retrieval."""
    response = lambda_client.invoke(
        FunctionName='pharma-context-provider',
        InvocationType='RequestResponse',
        Payload=json.dumps({
            'embedding': query_embedding,
            'n_results': top_k
        })
    )
    result = json.loads(response['Payload'].read())
    return json.loads(result['body'])
```

## Deployment Steps

1. **Create Lambda Layer** (one-time):
   ```bash
   bash aws/scripts/2_create_lambda_layer.sh
   ```

2. **Upload ChromaDB to S3**:
   ```bash
   python aws/scripts/1_upload_chroma_to_s3.py
   ```

3. **Deploy Lambda Function**:
   ```bash
   bash aws/scripts/3_deploy_lambda.sh
   ```

4. **Configure Warm-up Schedule**:
   ```bash
   bash aws/scripts/5_setup_warmup.sh
   ```

5. **Test Lambda**:
   ```bash
   python aws/scripts/4_test_lambda.py
   ```

## Updating Documents (Quarterly)

When FDA guidance changes:

1. Update local ChromaDB:
   ```bash
   uv run python scripts/update_chroma.py
   ```

2. Re-upload to S3:
   ```bash
   python aws/scripts/1_upload_chroma_to_s3.py
   ```

3. Lambda picks up new data automatically on next cold start

## Common Issues to Avoid
- Lambda /tmp storage is limited to 512MB by default; use ephemeral-storage=1024 for ChromaDB
- Layer size limit is 250MB unzipped; strip test files from chromadb package
- Global variable caching requires warm Lambda; EventBridge schedule maintains warmth
- S3 bucket must be in same region (eu-west-2) to minimize latency
