# Task B7 — Create Minimal Transfer Archive

**Phase:** 5 (Ops) | **Day:** 5
**Dependencies:** None
**Branch:** `feature/mes-agentic-bi`
**Status:** TODO

## Objective

Create a Bash script that builds a minimal `.tar.gz` archive (~6-9 MB compressed) containing only the core files needed to run the app in a new environment. Excludes all rebuildable artifacts (node_modules, .venv, .git, ChromaDB, .terraform, caches). Generates a `TRANSFER_README.md` with setup instructions and a `.env.transfer` with safe placeholder keys (no real secrets).

## Implementation Details

### 1. create_transfer_archive.sh

**Core logic:**

```bash
#!/usr/bin/env bash
set -euo pipefail

PROJECT_ROOT="$(cd "$(dirname "$0")/.." && pwd)"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
ARCHIVE_NAME="thesis_project_transfer_${TIMESTAMP}"
STAGING_DIR="/tmp/${ARCHIVE_NAME}"

# Rsync core dirs with exclusions
rsync -a --exclude='node_modules' --exclude='.next' --exclude='out' \
  --exclude='__pycache__' --exclude='*.pyc' \
  --exclude='chroma_db_v1020' --exclude='chroma_db' \
  --exclude='logs/traces' --exclude='logs/langfuse' \
  --exclude='output' --exclude='coverage_reports' --exclude='keys' \
  --exclude='archived' --exclude='tests/archive' \
  "${PROJECT_ROOT}/main/" "${STAGING_DIR}/main/"

# Copy docs, PRPs, prompts, aws (no .terraform), scripts, .claude, .github
# Copy root config files explicitly (pyproject.toml, Dockerfiles, compose files, etc.)
# Copy single BI demo CSV: demo_data/MES_PPRS_PLANT_PERFORMANCE_2024_2025.csv

# Generate .env.transfer from .env.example (safe placeholders)
cp "${PROJECT_ROOT}/.env.example" "${STAGING_DIR}/.env.transfer"

# Generate TRANSFER_README.md inline (heredoc)
# Contents: prerequisites, setup steps, rebuild table, API key guidance

# Create archive
cd /tmp && tar czf "${PROJECT_ROOT}/${ARCHIVE_NAME}.tar.gz" "${ARCHIVE_NAME}/"

# Report size, warn if >25 MB
```

### 2. TRANSFER_README.md (generated by script)

Covers:
- Prerequisites: Python 3.12+, Node 18+, uv, Docker
- Step-by-step: extract → `cp .env.transfer .env.local` → edit keys → `uv sync` → `npm install` → rebuild ChromaDB → run
- Table of excluded dirs and rebuild commands
- API key security guidance (generate fresh, never email real keys)

### 3. .env.transfer

Copy of `.env.example` (already contains safe placeholder values like `sk-or-v1-xxx...`). No real secrets.
