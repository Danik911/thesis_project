# Task L4.1 – Build Chat Backend

## What to Do
- Implement `main/src/lims/chat_agent.py` with a LlamaIndex chat engine.
- Chat context includes: full PDF content, current MDA state (all 4 core sheets), extraction citations.
- Chat can answer questions about extraction decisions.
- Chat can modify the MDA template when the operator requests changes.
- After each modification, validate the updated MDA against Pydantic models.
- Implement short-term chat memory per `job_id` (in-memory): messages, modification log, latest validated MDA state.
- Add memory guardrails: TTL (e.g., 2 hours) and max-turn cap (e.g., 50 messages) to prevent context bloat.
- Ensure final export uses the latest validated refined MDA state (not the initial generation snapshot).
- Wire to `POST /lims/chat` endpoint.

## Dependencies
- L2.2 (MDA generation workflow provides the initial MDA to chat about).

## Best Practices
- Use OpenRouter for LLM calls (GPT-5 or Claude Opus 4.6) via OpenAI-compatible SDK.
- Include the full MDA as structured context in the system prompt.
- Use function calling / tool use to structure MDA modifications as `MDAEditAction` objects.
- Always validate modified MDA with Pydantic before accepting changes.
- Never apply modifications that fail validation — return error to user.
- Structured edit actions only — no free-form MDA mutation.

## Code Example
```python
# main/src/lims/chat_agent.py
from openai import AsyncOpenAI
from pydantic import BaseModel
from typing import Optional, List
from datetime import datetime
from main.src.lims.mda_schema import MDATemplate
from main.src.lims.config import LIMSConfig

class MDAEditAction(BaseModel):
    """Structured MDA modification from chat."""
    sheet: str           # Which sheet: "analyses", "components", "calc_variables", "calculations"
    action: str          # "add", "modify", "delete"
    target: dict         # Identifier (e.g., {"analysis": "AND_ACS_DYE", "component_name": "DYE_VOLUME"})
    changes: dict        # Field changes to apply
    reason: str          # Why this change was made

class ModificationLog(BaseModel):
    timestamp: datetime
    message: str
    edit_action: MDAEditAction
    before: dict
    after: dict

class MDAChatAgent:
    def __init__(self, mda: MDATemplate, pdf_text: str, config: LIMSConfig):
        self.mda = mda
        self.pdf_text = pdf_text
        self.config = config
        self.messages: list = []
        self.modification_log: List[ModificationLog] = []
        self.llm_client = AsyncOpenAI(
            base_url="https://openrouter.ai/api/v1",
            api_key=config.openrouter_api_key,
            default_headers={"HTTP-Referer": "http://localhost:3000"},
        )

    async def chat(self, message: str) -> dict:
        """Process chat message, potentially modifying MDA."""
        self.messages.append({"role": "user", "content": message})

        response = await self.llm_client.chat.completions.create(
            model=self.config.openrouter_model,
            messages=[
                {"role": "system", "content": self._build_system_prompt()},
                *self.messages,
            ],
            tools=self._get_edit_tools(),
        )

        assistant_msg = response.choices[0].message
        self.messages.append({"role": "assistant", "content": assistant_msg.content})

        result = {"response": assistant_msg.content}

        # Check for tool calls (MDA modifications)
        if assistant_msg.tool_calls:
            for tool_call in assistant_msg.tool_calls:
                if tool_call.function.name == "modify_mda":
                    edit_action = MDAEditAction.model_validate_json(tool_call.function.arguments)
                    before = self.mda.model_dump()
                    try:
                        self.mda = self._apply_modification(edit_action)
                        MDATemplate.model_validate(self.mda.model_dump())  # Re-validate
                        after = self.mda.model_dump()
                        self.modification_log.append(ModificationLog(
                            timestamp=datetime.now(),
                            message=message,
                            edit_action=edit_action,
                            before=before,
                            after=after,
                        ))
                        result["updated_mda"] = self.mda.model_dump()
                    except Exception as e:
                        result["error"] = f"Modification rejected: {e}"

        return result

    def _build_system_prompt(self) -> str:
        return f"""You are an AI assistant helping a pharmaceutical operator refine an MDA template.
You have access to:
1. The original PDF test method content
2. The current MDA template state (4 core sheets)
3. Extraction citations explaining why fields were set to specific values

Current MDA state:
{self.mda.model_dump_json(indent=2)}

When the user asks to modify the MDA, use the modify_mda tool with a structured edit action.
Never make free-form changes — always use structured edits validated by Pydantic."""
```

```python
# Wire to API endpoint in lims_router.py
@router.post("/chat")
async def chat_message(request: dict):
    job_id = request["job_id"]
    message = request["message"]

    if job_id not in jobs or jobs[job_id]["status"] != "complete":
        raise HTTPException(status_code=404, detail="Job not found or not complete")

    # Get or create chat agent for this job
    if "chat_agent" not in jobs[job_id]:
        mda = MDATemplate(**jobs[job_id]["mda_template"])
        config = LIMSConfig()
        jobs[job_id]["chat_agent"] = MDAChatAgent(mda=mda, pdf_text="", config=config)

    agent = jobs[job_id]["chat_agent"]
    result = await agent.chat(message)

    # Update stored MDA if modified
    if "updated_mda" in result:
        jobs[job_id]["mda_template"] = result["updated_mda"]

    return result
```

## Testing Strategy
- Send a question about extraction: "Why did you set result_type to K for component X?" — returns explanation.
- Send a modification request: "Change units for component X to milligrams" — MDA is updated.
- Send an invalid modification: "Set result_type to Z" — returns Pydantic validation error, MDA unchanged.
- Chat maintains conversation context across messages.
- After modification, `GET /lims/status/{job_id}` returns the updated MDA.
- Verify chat memory expires after configured TTL.

## Common Issues to Avoid
- Don't apply modifications without Pydantic validation — this can corrupt the MDA.
- Don't lose conversation history between messages — maintain chat state per job.
- Don't use the LLM to validate MDA — use Pydantic (deterministic, not probabilistic).
- The `openai` SDK works with OpenRouter — just set `base_url="https://openrouter.ai/api/v1"`.
