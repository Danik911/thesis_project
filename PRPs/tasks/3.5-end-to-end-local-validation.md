**Required Implementation:**
```python
# Pseudo-code outline
async def process_job_worker(job_queue, job_repository, job_lock):
    while True:
        # 1. Poll SQS queue for messages
        messages = await sqs_client.receive_message(queue_url, max_messages=1)

        if messages:
            job_id = extract_job_id(message)

            # 2. Update job status: pending → processing
            await job_repository.update_status(job_id, "processing")

            # 3. Get URS file from storage
            urs_content = await storage_adapter.read_artifact(job_id, "urs_file.txt")

            # 4. Execute unified workflow
            from src.core.unified_workflow import UnifiedWorkflow
            workflow = UnifiedWorkflow()
            result = await workflow.run(urs_content=urs_content, job_id=job_id)

            # 5. Save generated test suite
            await storage_adapter.write_artifact(job_id, "test_suite.yaml", result.test_suite)

            # 6. Update job status: processing → completed
            await job_repository.update_status(job_id, "completed")

            # 7. Delete SQS message (acknowledge)
            await sqs_client.delete_message(message)

        else:
            await asyncio.sleep(5)  # Poll interval
```

**Critical:**
- NO FALLBACK LOGIC: All errors must raise exceptions
- Use `job_lock` to prevent concurrent processing
- Implement proper error handling with status updates to "failed"

## Known Issues & Mitigations

### Issue 1: Empty ChromaDB
**Problem:** Workflow fails if no documents in vector store
**Solution:** Run ingestion script before first test
**Check:** `docker exec pharma-api-dev python -c "from chromadb import Client; print(Client().get_collection('pharma_docs').count())"`

### Issue 2: API Key Errors
**Problem:** OpenRouter/OpenAI rate limits or invalid keys
**Solution:** Verify keys work before testing: `curl -H "Authorization: Bearer $OPENROUTER_API_KEY" https://openrouter.ai/api/v1/models`

### Issue 3: Worker Not Picking Up Jobs
**Problem:** SQS polling not working
**Debug:** `docker exec pharma-localstack-dev awslocal sqs receive-message --queue-url http://localstack:4566/000000000000/testgen-jobs --region eu-west-2`

### Issue 4: Workflow Timeout
**Problem:** Job exceeds 2-minute timeout
**Solution:** Increase timeout to 10 minutes (workflow needs 5-6 minutes)
**Config:** Update `MAX_EXECUTION_TIME` in worker

### Issue 5: Phoenix Not Capturing Traces
**Problem:** PHOENIX_ENABLE_TRACING not set
**Solution:** Verify in `.env.local`: `PHOENIX_ENABLE_TRACING=true`

### Issue 6: Permission Errors on /app/output
**Problem:** Root-owned volume directories
**Solution:** `docker exec -u root pharma-api-dev chown -R appuser:appuser /app/output /app/chroma_db`

### Issue 7: WSL2 Memory Exhaustion
**Problem:** Watchfiles causing OOM
**Solution:** Ensure `UVICORN_RELOAD=0` in `.env.local`
