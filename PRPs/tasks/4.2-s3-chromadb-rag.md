# Task P4.2 – S3 + Embedded ChromaDB RAG Deployment

## Status: COMPLETED

**Last Updated:** 2025-12-02

## What to Do
Deploy ChromaDB-based RAG context provider embedded in ECS Worker with S3 storage for production AWS deployment.

## Architecture Decision

**Original plan:** Aurora Serverless v2 + pgvector (~$150/month)
**Revised plan:** Lambda + S3 ChromaDB (~$2/month)
**Final approach:** Embedded Worker + S3 Download (~$0.02/month)

```
┌─────────────────────────────────────────────────────────────┐
│       Context Provider Architecture (eu-west-2 London)      │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   S3 Bucket (pharma-test-gen-chromadb-{account})            │
│   └── chroma_db.tar.gz (compressed ~2MB)                    │
│                                                              │
│   ECS Worker (4 vCPU, 8GB RAM)                              │
│   ┌────────────────────────────────────────┐                │
│   │  1. On startup: Download from S3       │                │
│   │  2. Extract to /app/chroma_db          │                │
│   │  3. Initialize ChromaDB PersistentClient│               │
│   │  4. Query in-process (<10ms latency)    │                │
│   └────────────────────────────────────────┘                │
│                                                              │
│   Same code path as local development!                       │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### Why Embedded Worker (vs Lambda)

| Factor | Lambda | Embedded Worker |
|--------|--------|-----------------|
| Monthly Cost | ~$2 | ~$0.02 |
| Latency | 50-100ms (network) | <10ms (in-process) |
| Cold Start | 5-10s Lambda init | 5-10s container start |
| Complexity | Lambda + Layer + EventBridge | Just S3 bucket |
| Code Changes | New Lambda client | Minimal (startup script) |

## Common Issues to Avoid

1. **Terraform requires prerequisites** - VPC, subnets, Aurora ARNs must exist or use placeholders
2. **S3 bucket naming** - Must be globally unique, includes account ID
3. **IAM permissions** - Worker task role needs `s3:GetObject` on ChromaDB bucket
4. **Region consistency** - All resources must be in `eu-west-2`
5. **Collection name** - Must be `pharmaceutical_regulations` (not `regulatory_docs`)
