# Debug Scripts

This directory contains diagnostic and debugging scripts used during thesis development to investigate specific issues.

## Important Notes

- **NOT production tests** — these are one-off debugging utilities
- **May reference outdated APIs** — some scripts may reference removed dependencies (e.g., Phoenix was replaced by LangFuse)
- **Educational value** — kept as examples of debugging patterns for the pharmaceutical test generation system
- **Obsolete patterns** — scripts investigate ChromaDB state, categorization loops, QA failures, and other issues that may have been resolved
