#### Finding 30: [HIGH] SQL Injection Vulnerability (Limited Scope)

**File:** `main/scripts/export_phoenix_from_db.py`
**Line:** 56
**Pattern:** f-string SQL query with variable table name

**Code:**
```python
for table in tables:
    table_name = table[0]
    cursor.execute(f"SELECT COUNT(*) FROM {table_name}")
```

**Risk:**
- SQL injection if `table_name` is user-controlled
- **MITIGATED:** Input comes from SQLite system tables (not user input)
- Still violates secure coding best practices

**Remediation:**
```python
# SAFE VERSION (parameterized query with identifier quoting)
import sqlite3

for table in tables:
    table_name = table[0]
    # Validate table name against whitelist
    cursor.execute("SELECT name FROM sqlite_master WHERE type='table' AND name=?", (table_name,))
    if cursor.fetchone():
        # Use identifier quoting to prevent injection
        cursor.execute(f'SELECT COUNT(*) FROM "{table_name}"')
```

**Reference:**
- OWASP A03:2021 - Injection
- CWE-89: SQL Injection

#### Finding 32: [MEDIUM] Command Injection with shell=True

**File:** `main/setup_phoenix.py`
**Line:** 20
**Pattern:** `subprocess.run()` with `shell=True`

**Code:**
```python
def run_command(cmd: str, description: str) -> bool:
    """Run a command and return success status."""
    result = subprocess.run(cmd, check=False, shell=True, capture_output=True, text=True)
```

**Risk:**
- Command injection if `cmd` contains user input
- **MITIGATED:** Function appears to use hardcoded commands only
- Still violates secure coding best practices

**Remediation:**
```python
# SAFE VERSION (shell=False with list argument)
def run_command(cmd: list[str], description: str) -> bool:
    """Run a command and return success status."""
    result = subprocess.run(cmd, check=False, shell=False, capture_output=True, text=True)

# Usage
run_command(["docker", "ps"], "Check Docker status")
```

- OWASP A03:2021 - Injection
