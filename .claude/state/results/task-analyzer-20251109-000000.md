#### 1. Create S3 Buckets for Compliance Logs (3-Bucket Architecture)
**Navigation:** AWS Console → S3 → Create bucket

**Architecture Update:** Using **3 separate buckets** for better organization:
- `pharma-cloudtrail-logs-eu` - CloudTrail API call logs
- `pharma-config-logs-eu` - AWS Config configuration snapshots
- `pharma-test-output-compliance` - Application test generation outputs

**Console Steps (repeat for each bucket):**
1. Navigate to **S3** service
2. Click **Create bucket**
3. **Bucket name:** (see list above)
4. **Region:** eu-west-2 (London)
5. **Object Ownership:** ACLs disabled (recommended)
6. **Block Public Access:** Block ALL public access (check all boxes)
7. **Bucket Versioning:** Enable
8. **Default encryption:** AES256 (SSE-S3)
9. Click **Create bucket**

**CLI Alternative:**
```bash
# Create CloudTrail logs bucket
aws s3api create-bucket \
  --bucket pharma-cloudtrail-logs-eu \
  --region eu-west-2 \
  --create-bucket-configuration LocationConstraint=eu-west-2

# Create Config logs bucket
aws s3api create-bucket \
  --bucket pharma-config-logs-eu \
  --region eu-west-2 \
  --create-bucket-configuration LocationConstraint=eu-west-2

# Create application compliance bucket
aws s3api create-bucket \
  --bucket pharma-test-output-compliance \
  --region eu-west-2 \
  --create-bucket-configuration LocationConstraint=eu-west-2

# Enable versioning on all buckets
for bucket in pharma-cloudtrail-logs-eu pharma-config-logs-eu pharma-test-output-compliance; do
  aws s3api put-bucket-versioning \
    --bucket $bucket \
    --versioning-configuration Status=Enabled

  aws s3api put-public-access-block \
    --bucket $bucket \
    --public-access-block-configuration \
      BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
done
```

**Store Results:**
- CloudTrail S3 bucket: pharma-cloudtrail-logs-eu
- CloudTrail bucket ARN: `arn:aws:s3:::pharma-cloudtrail-logs-eu`
- Config S3 bucket: pharma-config-logs-eu
- Config bucket ARN: `arn:aws:s3:::pharma-config-logs-eu`
- Application S3 bucket: pharma-test-output-compliance
- Application bucket ARN: `arn:aws:s3:::pharma-test-output-compliance`

#### 1. Create S3 Bucket for Terraform State
**Navigation:** AWS Console → S3 → Create bucket

**Console Steps:**
1. Navigate to **S3** service
2. Click **Create bucket**
3. **Bucket name:** `pharma-tfstate-eu`
4. **Region:** eu-west-2 (London)
5. **Object Ownership:** ACLs disabled
6. **Block Public Access:** Block ALL public access (critical for security)
7. **Bucket Versioning:** Enable (critical for rollback)
8. **Default encryption:** SSE-S3 (or SSE-KMS for enhanced security)
9. **Object Lock:** Optional (enable for compliance, requires contacting AWS support)
10. Click **Create bucket**

**CLI Alternative:**
```bash
# Create Terraform state bucket
aws s3api create-bucket \
  --bucket pharma-tfstate-eu \
  --region eu-west-2 \
  --create-bucket-configuration LocationConstraint=eu-west-2

# Enable versioning (CRITICAL)
aws s3api put-bucket-versioning \
  --bucket pharma-tfstate-eu \
  --versioning-configuration Status=Enabled

# Block public access
aws s3api put-public-access-block \
  --bucket pharma-tfstate-eu \
  --public-access-block-configuration \
    BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true

# Enable default encryption
aws s3api put-bucket-encryption \
  --bucket pharma-tfstate-eu \
  --server-side-encryption-configuration \
    '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"AES256"}}]}'
```

**Store Results:**
- S3 bucket name: pharma-tfstate-eu
- S3 bucket ARN: `arn:aws:s3:::pharma-tfstate-eu`
