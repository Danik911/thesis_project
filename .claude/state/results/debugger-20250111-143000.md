## Root Cause Analysis

**Why violations persisted after initial fixes:**

1. **Incorrect Target:** Initial fixes focused on observability page, but violations were from homepage
2. **Load Order:** Homepage renders first when user visits site, so violations appeared immediately
3. **Multiple States:** Homepage has 3 render states (loading, redirecting, main content) - all needed fixes
4. **Missed Coverage:** Loading state was not analyzed in initial accessibility audit
5. **Observability States:** After fixing homepage, observability page showed violations because all 4 render states lacked explicit main landmarks

**Lesson:** When debugging persistent violations, analyze ALL render states of ALL pages. Pages with conditional rendering (error/loading/success states) need special attention to ensure EVERY state has proper structure.
