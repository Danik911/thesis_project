## Implementation Summary
Created `main/src/lims/xlsx_exporter.py` -- a single-file XLSX exporter that converts an `MDATemplate` Pydantic model into a 4-sheet LabWare MDA format workbook using openpyxl. The function `export_mda_to_xlsx(mda: MDATemplate) -> bytes` returns raw XLSX bytes ready for streaming or file saving.

## Design Decisions
1. **Sheet definitions as module-level constant** -- `_SHEET_DEFINITIONS` maps each sheet name to its ordered column keys. This makes the mapping between MDATemplate fields and XLSX columns explicit and easy to maintain.
2. **Helper functions for separation of concerns** -- `_write_header_row`, `_write_data_rows`, `_auto_fit_columns`, and `_format_cell_value` are isolated helpers. Each has a single responsibility, making testing straightforward.
3. **First sheet uses `wb.active`** -- Per the task requirement, the first sheet (Analysis) reuses the default active worksheet from `openpyxl.Workbook()`. Subsequent sheets use `wb.create_sheet()`.
4. **Bool check before None check in _format_cell_value** -- Python `bool` is a subclass of `int`, so the bool check must come first to avoid treating `True`/`False` as integers.
5. **No fallback logic** -- If `wb.active` is `None` (should never happen), a `RuntimeError` is raised with a diagnostic message. All other errors propagate naturally.
6. **Empty string for None values** -- When a field is `None`, the cell value is set to `""`. openpyxl internally stores this as `None` when read back, but the cell displays as blank, which is the correct LabWare behavior.
