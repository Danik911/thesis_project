## Design Decisions

1. **Manual Langfuse Tracing Instead of Decorator**
   - Rationale: The `@observe` decorator serializes ALL function inputs, but `UploadFile` contains non-serializable `SpooledTemporaryFile` objects causing infinite hang
   - Solution: Use `langfuse.trace()` with explicit input filtering (only serialize safe metadata like filename, content_type)
   - Trade-off: Slightly more verbose code, but avoids the serialization issue entirely

2. **Logging Configuration at Module Top**
   - Rationale: Python's logging module can have WeakRef circular reference issues if accessed before `basicConfig()` is called
   - Solution: Moved `logging.basicConfig()` to be the FIRST code after the module docstring
   - Added `force=True` to ensure reconfiguration if already set by other modules

3. **APPROVED Status in Restartable Jobs**
   - Rationale: If worker restarts after job is APPROVED but before workflow resumes, the job would be stuck
   - Solution: Include APPROVED in `get_pending_jobs()` so approved jobs are re-enqueued on startup
   - ALCOA+ Compliance: Human approval decision is preserved in `human_category` field

4. **Pre-Approved Category Detection**
   - Rationale: Jobs re-enqueued after HIL approval need to skip categorization step
   - Solution: Check `job.human_category` in `_process_job_with_retries()` before workflow execution
   - If set, pass as `approved_category` parameter to skip LLM categorization
