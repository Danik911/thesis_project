### Root Cause (Primary)

**File**: `main/api/worker.py` lines 89-98

```python
# Initialize workflow executor (single instance, reused across jobs)
executor = None
try:
    logger.info("Initializing WorkflowExecutor...")
    executor = WorkflowExecutor()  # <-- FAILS HERE
    logger.info("WorkflowExecutor initialized successfully")
except Exception as e:
    logger.exception(f"CRITICAL: Failed to initialize WorkflowExecutor: {e}")
    logger.error("Worker cannot process jobs without executor. Exiting.")
    return  # <-- WORKER EXITS, NEVER ENTERS JOB PROCESSING LOOP
```

**Why WorkflowExecutor() Fails**:

**File**: `main/api/worker_executor.py` lines 97-110

```python
def __init__(
    self,
    storage_adapter: LocalStorageAdapter | None = None,
    vector_adapter: ChromaVectorStoreAdapter | None = None
):
    self.storage_adapter = storage_adapter or LocalStorageAdapter(base_path="/app/output")
    self.vector_adapter = vector_adapter  # <-- DEFAULTS TO None!
```

**Why None Vector Adapter Fails**:

When UnifiedWorkflow executes, it tries to use `self.vector_adapter` for RAG operations. If it's None, the workflow crashes with:

```
AttributeError: 'NoneType' object has no attribute 'retrieve'
```

OR ChromaDB initialization fails if path doesn't exist in Docker:

```
RuntimeError: CRITICAL: ChromaDB initialization failed
Persist path: ./chroma_db
Error: [Errno 2] No such file or directory: './chroma_db'
```

## Fixes Implemented

### Iteration 1: Fix WorkflowExecutor Initialization

#### Fix 1A: Initialize ChromaVectorStoreAdapter in WorkflowExecutor.__init__()

**File**: `main/api/worker_executor.py`
**Lines**: 109-110
**Issue**: vector_adapter defaults to None, causing workflow to crash
**Fix**: Initialize ChromaVectorStoreAdapter with proper persistent path

**Old Code**:
```python
self.storage_adapter = storage_adapter or LocalStorageAdapter(base_path="/app/output")
self.vector_adapter = vector_adapter
```

**New Code**:
```python
self.storage_adapter = storage_adapter or LocalStorageAdapter(base_path="/app/output")

# Initialize vector adapter if not provided (CRITICAL for workflow execution)
if vector_adapter is None:
    logger.info("Initializing default ChromaVectorStoreAdapter...")
    # Use absolute path in Docker container
    chroma_path = os.getenv("CHROMA_PERSIST_PATH", "/app/chroma_db")
    self.vector_adapter = ChromaVectorStoreAdapter(
        persist_path=chroma_path,
        collection_name="pharma_docs"
    )
    logger.info(f"ChromaVectorStoreAdapter initialized at {chroma_path}")
else:
    self.vector_adapter = vector_adapter
    logger.info("Using provided ChromaVectorStoreAdapter")
```

**Validation**: This ensures vector_adapter is NEVER None when UnifiedWorkflow runs.
