**Rationale**: Previous 0.7 threshold too lenient for pharmaceutical systems. 85% confidence ensures higher quality categorization decisions before bypassing human review.

**Rationale**: New ambiguity fields use fallback-free defaults (False, None) to prevent masking failures while maintaining backward compatibility with existing parsing infrastructure.
